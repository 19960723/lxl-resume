# 前端学习目录

这个目录用于沉淀前端求职和中高级能力补强资料。

## 推荐阅读顺序

1. `前端岗位能力补强路线图.md`：总路线、能力地图、16 周执行计划。
2. `前端岗位能力补强思维导图.mmd`：独立 Mermaid 思维导图源码，可复制到支持 Mermaid 的编辑器查看。
3. `项目作品集规划.md`：Vue3、React、性能优化、AI Native 项目的作品集设计。
4. `AI协作开发经验模板.md`：AI Native 岗位投递回答、Prompt、Review 清单。
5. `js.md`、`ts.md`、`vue.md`、`react.md`：按路线图逐步补充的技术笔记。

## 当前学习主线

- 第一阶段：JS / TS / 浏览器基础补强。
- 第二阶段：Vue3 + TS 中后台项目。
- 第三阶段：React + TS 数据看板项目。
- 第四阶段：性能优化、Playwright、AI 协作流程。
- 第五阶段：简历项目表达和面试复盘。
